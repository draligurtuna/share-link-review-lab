1. Inspect a public address

Use public page addresses only. Do not paste private links, health information, login credentials or tokens. The worksheet code makes no fetch, storage or submission requests; the hosting provider has its own policies.

Exact lowercase keys: utm_source, utm_medium, utm_campaign, utm_term, utm_content, utm_id. Everything else is retained.

This is a syntax and query-policy worksheet. It does not verify HTTP status, redirects, canonical tags, indexing, safety, rankings or content accuracy.
